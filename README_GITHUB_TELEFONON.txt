WDEA DEX WORLD – GitHub Pages, telefonról

A játék egyetlen fájl: index.html. Nem kell külön assets mappa vagy build eszköz.

Feltöltés Android telefonról:
1. Nyisd meg a github.com oldalt Chrome-ban, és lépj be.
2. Hozz létre egy új, Public repositoryt, például dex-world néven.
3. A repóban válaszd az Add file > Upload files lehetőséget.
4. Válaszd ki ezt az index.html fájlt, majd nyomj Commit changes-t.
5. Nyisd meg a repó Settings > Pages menüjét.
6. Build and deployment alatt válaszd a Deploy from a branch lehetőséget.
7. Branch: main; Folder: /(root); Save.
8. Várj, amíg a Pages közzéteszi, majd nyisd meg a megjelenő https://...github.io/... címet.

Telefonos játékvezérlés: a bal joystickkal mozogj, a jobb oldali joystickkal fordulj. Menj a kristályokhoz a felvételhez. A kapuknál nyomd meg az E billentyűt (VR kontrolleren az A gomb). A képernyőn a VR gomb csak kompatibilis böngészőn/eszközön jelenik meg.

Megjegyzés: GitHub Pages HTTPS-t ad, ami szükséges a WebXR kéréshez; a VR ettől még headset- és böngészőfüggő. A normál telefonos mód joystickkal működik.
